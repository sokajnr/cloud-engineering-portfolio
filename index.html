AWS Security | IAM Testing Completed

AWS Cloud Security Lab — Amazon S3 & IAM

Designed and configured a private Amazon S3 bucket with Block Public Access enabled, disabled ACLs, and server-side encryption using SSE-S3.

Developed a custom IAM read-only policy following the principle of least privilege and created an Amazon EC2-trusted IAM role with permissions restricted to a designated S3 bucket.

Security Validation: Completed four AWS IAM Policy Simulator tests. ListBucket and GetObject returned Allowed, while PutObject and DeleteObject returned Denied, matching the expected permission behavior.

Testing Scope: Preliminary IAM simulation completed. Bucket-specific authorization and live EC2 workload access have not yet been verified. An AWS Organizations SCP restriction was also observed during testing.

Technologies: Amazon S3, AWS IAM, IAM Roles, IAM Policies, IAM Policy Simulator, JSON, Cloud Security

Status: Infrastructure configured and four preliminary IAM security tests completed. Runtime validation pending.
